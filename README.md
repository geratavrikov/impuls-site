# Impuls — сайт рекламного агентства (Астана)

Готовый статический сайт-визитка: **1 страница** + страница политики конфиденциальности.
Без баз данных, без сборки — это просто файлы, которые можно открыть или загрузить на любой хостинг.

**Палитра:** белый / оранжевый / чёрный
**Язык:** русский
**Данные:** взяты с карточки 2ГИС (адрес, телефон, рейтинг, отзывы) и из присланного бренд-борда с услугами.

---

## 1. Что внутри

```
impuls-site/
├── index.html                  главная страница (всё в одном месте)
├── privacy.html                политика конфиденциальности
├── site.webmanifest            PWA-манифест (иконка, имя для телефона)
├── robots.txt                  правила для поисковиков
├── sitemap.xml                 карта сайта
├── README.md                   этот файл
└── assets/
    ├── css/style.css           все стили
    ├── js/app.js               слайдер, галерея, лайтбокс, меню, форма
    ├── works/                  21 фото работ (большие, до 1600 px)
    │   └── thumb/              те же фото уменьшенные (для сетки)
    ├── favicon.svg             иконка сайта
    ├── apple-touch-icon.png    иконка для iPhone
    └── og-image.jpg            картинка для превью в WhatsApp/Telegram
```

**Что есть на странице:**

1. Шапка с логотипом, меню, телефоном и кнопкой WhatsApp
2. Первый экран: заголовок + автоматический слайдер работ
3. Бегущая строка с направлениями
4. Услуги (6 карточек + 6 дополнительных направлений)
5. «Наши работы» — горизонтальная галерея из 21 фото, листается пальцем/мышью, фото открывается на весь экран
6. О компании + цифры (5.0 на 2ГИС, 22 отзыва, 13+ направлений, 24/7)
7. Этапы работы (6 шагов)
8. Отзывы клиентов (реальные, из 2ГИС)
9. Блок с призывом + кнопки WhatsApp / звонок
10. Контакты + карта + «Маршрут в 2ГИС» / Google Maps
11. Подвал, плавающая кнопка WhatsApp, кнопка «наверх»
12. Форма «Рассчитать стоимость» → заявка уходит вам в WhatsApp (сервер не нужен)

## 2. Как посмотреть локально

Просто откройте `index.html` двойным щелчком.
Шрифты Google и карта подгружаются из интернета — без сети страница откроется, но без карты и фирменного шрифта.

Чтобы всё работало «как на хостинге», можно запустить локальный сервер (если установлен Python):

```bash
cd impuls-site
python -m http.server 8080
```

и открыть `http://localhost:8080`.

## 3. Что менять в первую очередь

### Телефон, WhatsApp, e-mail

Номер `+7 705 111 62 11` встречается в нескольких местах. Быстрая замена — поиском по файлам:

| Что искать | Где |
|---|---|
| `77051116211` | ссылки `wa.me/...` (в `index.html`) — номер без «+» |
| `+77051116211` | ссылки `tel:+77051116211` |
| `+7 705 111 62 11` | видимый текст телефона |
| `Impuls.sign@gmail.com` | почта (в `index.html` и `privacy.html`) |
| `waNumber` | `assets/js/app.js` — номер, на который уходит форма |

> Если меняете номер — замените **все** варианты, иначе часть кнопок будет вести на старый номер.

### Адрес и карта

В `index.html` найдите блок `id="contacts"`:

* текст адреса — `ул. Сыганак, 54а`, `офис 1406-02, 14 этаж`;
* координаты в ссылке карты: `ll=71.417986%2C51.124297` и `pt=71.417986,51.124297`;
* координаты в микроразметке (`application/ld+json`) — поля `latitude` и `longitude`.

Новые координаты проще всего взять в 2ГИС/Яндекс.Картах: правый клик по точке → «что здесь» → скопировать широту/долготу.

### Услуги и тексты

Все тексты лежат прямо в `index.html` — блоки `<article class="service">` и `<div class="more-card">`.
Можно свободно добавлять/удалять карточки: сетка сама перестроится.

### Логотип

Логотип собран векторно из двух частей (это удобно — он не размывается и легко масштабируется):

```html
<span class="logo__mark" aria-hidden="true"></span>   <!-- оранжевая косая черта = буква I -->
<span class="logo__text">MPULS<span class="logo__sub">Рекламное агентство</span></span>
```

Стили — в `assets/css/style.css`, классы `.logo`, `.logo__mark`, `.logo__text`, `.logo__sub`.
Если понадобится поставить исходную картинку логотипа, замените эту конструкцию на
`<img src="assets/logo.png" alt="Impuls" class="logo__img">`.

### Фотографии работ

Файлы: `assets/works/work-01.jpg` … `work-21.jpg` (большие) и `assets/works/thumb/work-01.jpg` … (маленькие).
Количество задаётся одной строкой в `assets/js/app.js`:

```js
var WORK_COUNT = 21;
```

**Как заменить фото:**

1. Приведите фото к размеру примерно 1600 px по длинной стороне, JPG, качество 80–85.
2. Положите большую версию в `assets/works/`, маленькую (720 px) — в `assets/works/thumb/`.
3. Названия файлов должны совпадать (`work-01.jpg`, `work-01.jpg` в thumb).
4. Если фото больше или меньше — поменяйте `WORK_COUNT` в `app.js`.

Фото на первом экране (слайдер) задаются отдельно — найдите в `index.html` блок `hero-slider__track`.

## 4. Как опубликовать сайт

Нужен любой из вариантов. Домен можно привязать позже.

### Вариант A. Netlify Drop — самый быстрый (5 минут, бесплатно)

1. Откройте <https://app.netlify.com/drop>.
2. Перетащите папку `impuls-site` в окно браузера.
3. Через 10–20 секунд получите адрес вида `https://random-name.netlify.app`.
4. В настройках сайта: **Domain management → Add custom domain** — привяжите свой домен (например `impuls.kz`).
5. Там же включите бесплатный HTTPS (Let's Encrypt) — обычно он включается сам.

Обновление сайта: снова перетащите папку (или подключите Git-репозиторий).

### Вариант B. GitHub Pages — бесплатно, если есть GitHub

```bash
cd impuls-site
git init
git add .
git commit -m "Impuls site"
git branch -M main
git remote add origin https://github.com/USERNAME/impuls-site.git
git push -u origin main
```

Затем: **Settings → Pages → Source: Deploy from a branch → main / root** → Save.
Сайт будет на `https://USERNAME.github.io/impuls-site/`.

### Вариант C. Обычный казахстанский хостинг (PS.KZ, Hoster.KZ, reg.ru)

1. Купите домен + хостинг.
2. Через панель (ISPmanager/cPanel) или FTP загрузите **содержимое** папки `impuls-site` в `public_html` (или `www`).
3. Проверьте, что `index.html` лежит в корне.
4. В панели включите SSL (бесплатный Let's Encrypt) и редирект с `http` на `https`.

### После публикации — заменить домен

Сайт сейчас настроен на `https://impuls.kz/`. Если домен другой, замените его в:

* `index.html` — `<link rel="canonical">`, теги `og:url` / `og:image`, блок JSON-LD (`url`, `image`);
* `privacy.html` — не обязательно, но желательно;
* `robots.txt` — строка `Sitemap:`;
* `sitemap.xml` — оба `<loc>` и дата `<lastmod>`.

* Заголовок и описание с ключевыми словами («вывески Астана», «лайтбоксы», «объёмные буквы»).

3. Отправьте `sitemap.xml` на индексацию в обе панели.
4. Проверьте превью ссылки: вставьте адрес в чат WhatsApp и посмотрите, как выглядит карточка.

## 6. Технические детали

* Чистый HTML + CSS + JS (ES5), без фреймворков и зависимостей.
* Адаптив: 360 → 1440+ px. Проверено на 375 и 753 px — горизонтальной прокрутки нет.
* Анимации отключаются при `prefers-reduced-motion`.
* Галерея: свайп, стрелки, клавиатура (← → Esc), клик по фону закрывает.
* Форма заявки не отправляет данные на сервер — она формирует готовое сообщение и открывает WhatsApp. Это значит, что не нужны ни база, ни защита персональных данных на сервере.
* Карта — встроенный виджет Яндекс.Карт (без API-ключа). Если нужен виджет 2ГИС, замените `iframe` в блоке контактов.
